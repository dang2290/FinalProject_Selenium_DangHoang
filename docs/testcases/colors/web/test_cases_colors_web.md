**Quy ước Test Data:** `<ts>` = Unix timestamp (giây) lúc chạy, ví dụ `1793500000` → `AutoColor_TC004_1793500000`. Name giữ **≤ 30 ký tự** và **không có dấu cách** (trừ TC kiểm những điều đó) vì máy chủ cắt tên dài hơn và xoá dấu cách. **Color Code phải duy nhất toàn hệ thống:** các mã trong cột Test Data ghép theo mẫu `#<3 số TC><3 số cuối ts>` (ví dụ TC_004, `<ts>` kết thúc `000` → `#004000`), biến thể thay chữ số đầu bằng mã biến thể (`#a13000`). Gặp `The code has already been taken.` ở bước tiền đề thì đổi `<ts>` rồi tạo lại.

**Tag đặc biệt:** `@KnownIssue` — TC bám kỳ vọng đúng nhưng hệ thống hiện đang lệch (dự kiến FAIL) · `@AssumptionBased` — Expected dựa trên giả định Q1–Q11 user chấp nhận 02-11-2026 · `@NeedsVerify` — chưa có ảnh/thao tác thật chống lưng cho Expected.
